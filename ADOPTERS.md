# CKB Adopters

This page is for organisations, teams and individual developers who use CKB in real projects and are comfortable being publicly listed.

## Add your deployment

Open a pull request adding one row below. Please include only information you are authorised to publish.

| Organisation / project | How CKB is used | Public reference | Since |
|---|---|---|---|

A public reference can be a company page, repository, engineering post, integration documentation or another independently accessible source showing the deployment or use.

## Why this exists

CKB is an architecture-intelligence project. Public adopter records help maintainers understand real-world use cases, prioritise compatibility work and document the project's ecosystem without relying on unverified claims.
