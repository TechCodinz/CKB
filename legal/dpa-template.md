# DATA PROCESSING AGREEMENT
## Between CKB, Inc. and [Customer Name]

**Effective Date:** [Date]

### 1. PARTIES
**Data Controller:** [Customer Name] ("Controller")  
**Data Processor:** CKB, Inc. ("Processor")

### 2. SCOPE
This DPA applies when Processor processes Personal Data on behalf of Controller in connection with CKB services.

### 3. PROCESSING DETAILS

| Aspect | Details |
|--------|---------|
| **Subject Matter** | Code analysis services |
| **Duration** | Term of agreement |
| **Nature** | Collection, storage, analysis |
| **Purpose** | Architectural analysis |
| **Data Categories** | Code, user data, usage data |
| **Data Subjects** | Employees, contractors |

### 4. OBLIGATIONS OF PROCESSOR
4.1 Process only on documented instructions
4.2 Ensure confidentiality
4.3 Implement security measures
4.4 Assist with data subject rights
4.5 Notify of data breaches
4.6 Delete/return data on termination

### 5. OBLIGATIONS OF CONTROLLER
5.1 Lawful basis for processing
5.2 Accurate data provision
5.3 Response to data subject requests

### 6. SUB-PROCESSORS

**Current Sub-processors:**
- Stripe (payments)
- AWS (infrastructure)
- SendGrid (email)
- Intercom (support)

**Authorization:** Controller authorizes listed sub-processors. 30-day notice for changes.

### 7. DATA TRANSFERS
Standard Contractual Clauses (EU Commission Decision 2021/914) apply for international transfers.

### 8. SECURITY MEASURES
- Encryption (TLS/AES-256)
- Access controls
- Regular testing
- Employee training
- Incident response

### 9. BREACH NOTIFICATION
72-hour notification with:
- Nature of breach
- Categories affected
- Estimated risk
- Remediation steps

### 10. DATA SUBJECT RIGHTS
Processor shall assist Controller in responding to:
- Access requests
- Rectification
- Erasure
- Portability
- Objection

### 11. AUDIT RIGHTS
Annual audits with 30-day notice. Third-party auditor permitted.

### 12. RETURN/DELETION
Within 90 days of termination, Processor shall delete all data except as required by law.

### 13. LIABILITY
Each party liable for its own breaches. Total liability capped in main agreement.

### 14. GOVERNING LAW
Same as main agreement.
